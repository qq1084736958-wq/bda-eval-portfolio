# 产品概述 · 智能经营数据问答助手

> 一个局域网演示应用：手机端用自然语言查询经营数据，按账号权限返回可追溯的结果、图表和历史对话。页面业务数据均为可重复生成的模拟数据。

## 核心能力

- **持久化对话与历史**：每次问答保存对话、消息、状态和 `traceId`；历史仅显示当前账号记录，可搜索、筛选、查看详情并继续追问。
- **权限安全**：角色决定可访问的数据范围与金额精度；无权查看时只返回安全说明，图表/表格/来源记录不泄露越权明细。
- **可追溯回答**：经营类回答附口径版本、来源记录数与同步时间；知识库回答附文档引用与片段。
- **图表与表格**：权限允许时可切换表格/柱状/折线/环形图，小屏保持可读。
- **浏览器语音输入**：支持 Web Speech API 的浏览器可语音提问，发送前确认编辑；不支持时回退文字输入。

## 运营管理后台

16 个模块分四组：总览；问答运营（预设问题、未知问题池、用户反馈、问答日志）；知识与模型（知识库、知识点、指标口径、词库别名、业务术语、Prompt 工程台）；系统管理（功能模块、数据源监控、用户权限、审计日志、系统设置）。

## 技术形态（供参考）

- Next.js + React 全栈；结构化数据用关系型存储（Drizzle ORM），制度知识用向量库 RAG。
- 角色鉴权（JWT）、审计日志；答案结构化输出并携带来源引用。
- 评测侧：离线标注集 + 真实问题回流 + 自动/人工质量评审 + 回归基线。

## 典型用户路径

1. 用户输入自然语言问题，或从常用问题选择；
2. 系统识别问题类型（经营数据 / 制度知识 / 上下文追问 / 复合问题）；
3. 在权限范围内查询结构化数据 / 检索知识库；
4. 用户看到结论、数据口径、来源引用与下一步操作；
5. 可继续追问、反馈、查看历史；
6. 运营人员在后台查看 Trace、未知问题、反馈、知识库与评测结果，持续迭代。
