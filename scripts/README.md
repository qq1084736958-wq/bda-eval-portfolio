# 评测脚本（工作样本）

这三个脚本是我为「智能经营数据问答助手」搭建评测体系时编写的，在产品仓库内运行（依赖其数据层与助手管线）。此处作为**工作样本**展示实现思路，非独立可运行工程。

| 脚本 | 作用 |
|---|---|
| `export-eval-candidates.mjs` | 从运行库的未知问题池/用户反馈/问答日志**回流真实提问**，去重分桶，生成与标注集同格式的待标注候选用例 + 人工标注工作表。 |
| `run-offline-baseline.ts` | **确定性全量基线**：真实调用助手管线跑全部用例，汇总路由/状态准确率、RAG 引用命中、结构化取值正确率，并列出失败项。 |
| `run-answer-quality-judge.ts` | **自动五维 LLM-as-Judge**：复用产品 rubric（正确性/清晰度/依据充分性/可行动性/表达自然度），用跨家族评审模型给答案打分并汇总通过率。 |

结果见 `../reports/`，方法与发现见 `../docs/评测体系设计与发现.md`。
